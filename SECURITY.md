# Security and safe use

This repository contains a deliberately vulnerable, fictional training site with weak-cryptography and metadata-analysis challenges. It is for authorized learning in a local or isolated lab only.

## Scope

- Run the app on localhost or inside a disposable VM/network you control.
- Do not expose it to the public internet or connect it to real accounts, services, personal files, or production data.
- Use only the included synthetic challenge data. Do not replace it with real passwords, photos, or identifying metadata.
- The hash, cipher keys, and source comments are puzzle materials, not secrets or security controls.

## Reporting

If you find a defect in the training code, open a GitHub issue with a concise description and reproduction steps using only the local lab. Do not include real credentials, personal information, or data from systems outside the lab.
